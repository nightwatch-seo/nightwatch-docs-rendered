Nightwatch Looker Studio Connector

Steps to integrate Nightwatch with Google Looker Studio.

Written by Maja Nagelj
Updated over 3 months ago

The Nightwatch Looker Studio Connector lets you stream any ranking or website‑level metric from Nightwatch directly into Google Looker Studio.

Build fully‑custom dashboards by blending SEO data with GA4, Search Console, or any other source in the Google marketing stack.

Prerequisites
• A Nightwatch plan with API access (≥ 1,000 tracked keywords)
• A Google account with permission to create Looker Studio data sources
• Your Nightwatch API token

Step 1: Connect Nightwatch to Looker Studio

  • Go to Google Looker Studio and click Create > Data Source

  • Search for Nightwatch SEO Tracker

  • Authorize the connector with your Google account.

  • In Nightwatch, go to Settings > API Access and click Generate to get your API token

  • Paste the token into the connector and click Submit

Step 2: Choose Your Report Type

Select the report type that best fits your analysis goals — each one unlocks a different layer of Nightwatch data:

🔍 Keyword Rankings
Build detailed tables to explore keyword positions, ranking trends, search volume, and more. Ideal for audits and performance monitoring at scale.

📈 Individual Keyword Performance
Create time-based graphs to track ranking, impressions, CTR, and click data for specific keywords. Perfect for analyzing keyword behavior and change over time.

🌐 Website Metrics
Generate high-level overviews showing metrics like Average Position, Search Visibility Index, and Click Potential across your entire website.

📊 Graphs
Combine multiple metrics and dimensions (from Nightwatch, GA4, or GSC) into dynamic visualizations. Great for uncovering trends and insights at a glance.

🔎 Website View Stats
Visualize keyword distribution across custom Views or your whole site — track how different segments (e.g., branded vs non-branded, local vs global) perform over time.

👉 Tip: You can select one or multiple metrics from the list, depending on the report you want to build. You can always add more by adding multiple Data Sources.

Step 3: Select URLs and Views

  • Select the URL from all available tracked URLs and click Next:

(Optional) Select the view for more granular reports and keywords when creating a report for the Individual Keyword Performance metric

Here, you can select the view from the dropdown to create reports based on your segmented sets of keywords. This step is optional, and if you want to use the data for the entire URL, you can skip it.

When creating the Individual Keyword Performance report, select all the keywords that you want to add from the drop-down.

ℹ️ This step is obligatory if you select the Individual Keyword Performance report.

(Optional) You can include competitors' data.

Step 5: Creating New Reports Later

Already connected? Here’s how to build additional reports:

  1. Create a blank report in Looker Studio

  2. Select Nightwatch SEO Tracker as your data source

  3. Click Add a chart and begin designing your custom dashboard

💡 Please note that metrics are aggregated to sum or average by default, so depending on the selected metric, you will need to adjust it. E.g., if you are adding the Keyword Count metric to the report, you would want to set it to count instead of sum. You can easily change it in the setup tab.
